How it works

Guess a line

The robot starts with a totally random line. Probably a bad one!

Measure the oopsies

Each dot has a red spring pulling on the line. Long springs mean big mistakes.

Roll downhill

The springs tell the robot which way to nudge the line. It takes one small step that way.

Again and again

Step after step the springs shrink, until the line can't get any better.

What just happened?

  • We showed the robot examples with answers: temperature → cones sold.
  • It started with a wrong line and measured how wrong it was (the oopsie).
  • Each step it nudged the line in the direction that makes the oopsie smaller.
  • Too-big steps make it bounce around; tiny steps make it slow.
  • Now the line can predict cones for a temperature it never saw!
For grown-ups: what's really going on

This is simple linear regression: the model is ŷ = w·x + b, fit by minimising the mean squared error MSE = (1/n) Σ (ŷᵢ − yᵢ)². The red springs are the residuals ŷᵢ − yᵢ; the "oopsie" number is MSE in cones².

  • The robot uses gradient descent: w ← w − η·∂MSE/∂w, b ← b − η·∂MSE/∂b, with ∂MSE/∂w = (2/n) Σ (ŷᵢ−yᵢ)xᵢ and ∂MSE/∂b = (2/n) Σ (ŷᵢ−yᵢ). Inputs are centred and scaled internally, which makes the loss bowl round and training fast.
  • "Oopsie hills" is the loss landscape over (w, b). For MSE it is a convex bowl, so gradient descent always finds the bottom if the learning rate η is small enough; above 2/λ_max of the Hessian it oscillates and diverges.
  • The checkpoint strip is the same idea as saving model checkpoints during training: snapshots of the parameters at chosen steps.
  • Linear regression also has an exact closed-form answer (ordinary least squares, the flag). Gradient descent matters because the same loop trains neural networks with millions of weights, where no formula exists.
  • The weird day shows squared error is sensitive to outliers.
