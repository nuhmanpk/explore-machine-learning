What just happened?

  • The backpack holds a fixed number of words. Keep-last just drops the oldest ones, so early facts vanish first.
  • The summary squashes old lines into fewer words, but a squash can throw away the one line you needed.
  • Search memory keeps everything outside the backpack and fetches only the lines that match the question.
  • A bigger backpack costs more to carry, so clever memory lets a small one do the job of a big one.
  • Search can still miss: it only finds lines that share words with the question.
For grown-ups: what's really going on

A language model can only read a limited context window (measured in tokens; here, words). Anything outside it is invisible. An agent needs an external memory policy to decide what goes back in.

  • Keep-last-N (a sliding window): newest turns that fit the budget.
  • Summarise: half the budget is recent turns; older turns are compressed by removing stopwords and ranked by a hand-written importance score (digits and capitalised names), keeping the best that fit. A real system asks a model to write the summary, which is also lossy.
  • Retrieval (the idea behind RAG): one third recent turns, the rest the top-3 older turns by TF-IDF cosine similarity to the question. tfidf(w) = tf · (ln((N+1)/(df+1)) + 1), so rare words count for more than common ones.
  • Toy reader: a keyword and value matcher stands in for the language model that would read the context. Scores show whether the right line reached the context, which is the thing memory controls.
  • Metric: number of the 8 recall questions answered correctly. Facts lean towards the start of the chat, so small windows hurt.

Further reading: Lewis et al., Retrieval-Augmented Generation (2020) · Liu et al., Lost in the Middle (2023).
