What just happened?

  • You made groups and showed Robo examples of each one. That's called training data.
  • Robo didn't learn to see from zero: it borrowed eyes that already studied a million photos, and turned each example into a long list of numbers.
  • To guess, it found the examples most like the new picture and let them vote.
  • The checkpoints showed that more, varied examples make Robo surer — and that it can still be fooled by things it never saw.
For grown-ups: what's really going on
  • This is transfer learning, the same trick as Google's Teachable Machine. A MobileNet v2 CNN pretrained on ImageNet (1.28M images, 1000 classes) runs in your browser via TensorFlow.js.
  • We drop its final classification layer and use the penultimate activations (mobilenet.infer(img, true)) as an embedding: a 1280-dimensional feature vector that captures visual concepts.
  • The classifier is a hand-written k-nearest neighbours using cosine similarity on L2-normalised embeddings, with k = min(5, smallest class size). Each neighbour votes with weight exp(20·(sᵢ − s_max)), a softmax over similarities; confidence is the normalised vote share. The "self-quiz" is leave-one-out accuracy on (up to 80 of) your own examples. No gradient descent is needed, which is why "training" is instant.
  • The idea map is a live PCA (top two principal components, found by power iteration with deflation) of all stored embeddings. Clusters that separate in 2D are usually easy for KNN; overlapping ones are where it gets confused.
  • Failure modes worth exploring: background/lighting shortcuts (the model may learn "dark room" rather than "hand"), class imbalance, and too few varied examples. All images stay on your device.
