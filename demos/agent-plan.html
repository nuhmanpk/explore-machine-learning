      What just happened?

      • The greedy robot only looks at the next step, so it grabbed cheap steps that did not help, or one that used up something it needed.
      • The planner thinks ahead: it searches all the ways to reach the goal and picks the cheapest list of steps.
      • Steps depend on each other (you cannot butter bread you have not got), so the plan puts them in a working order.
      • When a step failed, the old plan was no use. Re-planning from where it stood found a new way.
      • The planning here is a plain search. A real agent may let a language model propose the plan and then check it the same way.
      For grown-ups: what's really going on

      Each action has preconditions, add effects, delete effects and a cost, as in STRIPS planning. A state is a set of true facts.

      • Greedy: pick the cheapest applicable action that adds a new fact, not tried before. It never looks ahead, so it can wander or use up a resource (the bread) that has no replacement: a dead end.
      • Planner: uniform-cost search (Dijkstra) over states finds the lowest-cost action sequence, so it is optimal for the actions it knows about. The search size is shown. State spaces grow exponentially, so real planners add heuristics (A*).
      • Topological order: from the plan we build a dependency graph (action A makes a fact action B needs) and sort it with Kahn's algorithm. Any such order is valid.
      • Failure and re-planning: a failed action pays its cost and is marked unavailable; the planner searches again from the current state without it (replanning). This is why agents re-check the world after each step.
      • No language model here: this is classical planning code. LLM agents often generate a plan in text, then execute and re-plan in the same way.
